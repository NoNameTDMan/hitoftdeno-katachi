# ひとふでのカタチ v0.1.0

マス目の集合を、一本の線ですべて通る日本語ブラウザパズルです。

## ルール
- 緑色のマスからスタートする
- 上下左右の隣のマスだけへ移動できる（斜めは不可）
- 同じマスは二度通れない
- すべてのマスを一度ずつ通過したらクリア

## 操作
- スマートフォン：緑のマスから指でなぞる。指を離しても末端から再開できる
- PC：マウスでドラッグ、または各マスを順番にクリック
- 直前のマスへ戻す：線の末端を前のマスへドラッグ／「ひとつ戻す」
- 「ヒント」：現在の経路から残りを埋められる場合、次の一手を黄色で表示。無理な場合はやり直しを促します
- キーボード：矢印キーで移動、Backspaceでひとつ戻す、Rでリセット、Hでヒント

## ステージ
- ステージ1～10は固定の入門問題
- ステージ11以降は、答えとなる一筆の経路を先に作ってから盤面に変換する手続き型生成。原理的に必ず少なくとも1通りの解が存在します
- クリアすると次の問題が解放されます
- 進行状況と効果音のオンオフはブラウザの localStorage に保存されます（キー：`hitofude-katachi-v010`）

## 公開方法
このフォルダの `index.html` を GitHub Pages の公開対象フォルダ（例：リポジトリのルート）に配置してください。必要なCSSとJavaScriptはすべてHTMLに内包されています。外部依存、外部通信、Service Workerはありません。

以前のゲームとは別の新規ゲームです。ほかのゲームのファイルや保存領域を変更しません。
